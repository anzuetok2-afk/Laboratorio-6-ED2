# Laboratorio-6-ED2
La práctica consiste en realizar un sistema capaz de medir la frecuencia y generar señales cuadradas mediante el uso de temporizadores internos del microcontrolador. Además, se utilizará la comunicación UART para enviar y recibir los datos correspondientes a las señales.
